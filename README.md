# Learning Notes
A running collection of my personal notes and summaries from courses and self-study, written as I learn programming — starting from fundamentals and moving into JavaScript and full-stack development.

## Why this repo exists
I'm documenting what I learn in public, as I build toward a career in programming. This is not a copy of course material — each file is my own summary, written after finishing a session or module, capturing what actually stuck.

## Structure
```
learning-notes/
├── README.md
├── Learn JavaScript: Fundamentals - CodeAcademy/
    └── Cheat-Sheet.md

*(Updated every time a new course folder is added | Last Update: 19.9.2026)*
```

- One folder per course, named with course provider.
- Files are short — a summary, not a transcript. Each one has: what the topic was, the core idea in my own words, and one thing I'd have gotten wrong before this session.m.
